# Metland School Library System

A digital library management platform built for SMK Pariwisata Metland to streamline academic catalog discovery, student book circulation, and library desk operations.

## Core Capabilities

- **Digital Book Catalog**: Categorized book discovery across vocational subjects, literature, natural sciences, and scholastic reference materials.
- **Student Circulation Portal**: Real-time stock visibility, self-service loan applications, overdue fine tracking, and digital library cards.
- **Librarian Desk Operations**: Circulation approval workflows, physical book return recording with automated fine calculation, and periodic activity summaries.
